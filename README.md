# 基于 RISC-V 常开小核的中文关键词唤醒系统（KWS / tinyML）

在算力与内存极度受限的常开（AON）小核上，端到端实现中文命令词唤醒系统：
从数据采集、数据工程、模型训练、INT8 量化，到板级部署与联调的完整链路。
唤醒/打开/关闭三类命令词 + 负类，命中后经核间中断唤醒主核（Alexa 同构架构）。

## 系统架构

麦克风 → Codec(48kHz) → VAD(硬件语音检测)
→ 抗混叠抽取(48k→16k, 31阶Q15 FIR)
→ log-Mel 特征(49×40) → 轻量 CNN 推理(INT8)
→ 决策(置信度+margin) → 命中 → mailbox 中断唤醒主核

模型权重 251KB 超过小核单片 SRAM(128KB)，最大全连接层(245KB)经 PSRAM
流式加载，双 ELF 烧录流程 + CRC32 校验保证权重完整。

## 技术要点

- 训练管线（Colab）：10 人录音自动切片；五路负样本体系（多音色 TTS 日常词、发音相近难负样本、真人朗读、英文词、流式随机窗）；先分文件再增强防泄漏；留一人跨人测试；类别权重平衡。
- INT8 训练后量化：representative dataset 标定数值范围，输入输出全整型。
- 抗混叠抽取：硬件 48kHz 与模型 16kHz 错配，自研 31 阶 Hamming FIR（fc=6.8kHz，Q15 定点），PC 先行验证再上板。
- 大权重部署：W4 层 PSRAM 流式读取 + 行缓存；烧录/正式双 ELF 流程；烧录与启动自检双 CRC32 指纹。
- 硬件联调：VAD 寄存器级排障、Codec I2C 配置 NACK 检测、QFN 封装外围焊盘测量定位。

## 目录结构

- training/   Colab 训练 notebook、权重导出脚本、PC 回归测试脚本
- firmware/   板端 C 代码（特征提取/推理/决策/PSRAM 流式/烧录）
- models/     训练产物（int8.tflite + 归一化参数 npz）
- docs/       测试记录与截图

## 复现流程

1. Colab 打开 training/ 下 notebook，按 cell 顺序执行（录音数据需自备）
2. 运行 export_weights.py <int8.tflite> 生成固件权重头文件
3. 固件集成到目标 MCU 工程，按 firmware/ 内注释对接音频前端
